# 原価ガードと黒字の式（AI返信秘書 backend）

正本の方針: `ai-generic-rules/docs/policies/COST_SAFETY_POLICY.md`（§A 黒字の式・§3 守りの6層）。
実装: [`src/cost-guard.js`](../src/cost-guard.js)。テスト: [`test/cost-guard.test.js`](../test/cost-guard.test.js)。

> ★この文書の数字（無料回数・上限・予算）は**提案**。最終決定は本人。
> 決めたら `wrangler.toml` の `[vars]` か `wrangler secret` で env に入れる（コードの既定値は env が空のときだけ使う）。

## 1. 有料の呼び出し（OpenRouter）はどこか

| 入口 | 1操作で呼ぶ回数 | max_tokens | プロンプトの長さ |
|---|---|---|---|
| `POST /inbox/assess`（受信の判定） | 1回（JSON が壊れていたら救済でもう1回 `openai/gpt-4o-mini`） | 1100 | 本文は3,000字まで（triage.js） |
| `POST /inbox/:id/draft`（返信の下書き） | 1回 | 800 | 本文は3,000字まで（draft-gen.js） |
| `POST /projects/:id/assist`（案件の照合・返信案） | 1回 | 1500 | **30,000字まで**（1発言1,500字・古い発言から落とす。落とした件数は画面に出す） |

どれもログイン（`requireAuth`）が必要。匿名の入口からは呼ばれない。

## 2. 守りの層（呼ぶ前に、上から順に全部通ったときだけ呼ぶ）

| 層 | 中身 | env | 止まったときの応答 |
|---|---|---|---|
| L1 キルスイッチ | 全部止める | `PAID_CALLS_DISABLED=1` | 503 `ai_paused` |
| プラン | 試用の期限切れ（`expired`）は止める | — | 402 `plan_expired`「無料お試し期間が終了しました…」 |
| L4 1人の上限 | 試用: 試用期間あたりの回数 / 有料: 月あたりの回数（1操作=1回） | `TRIAL_AI_CALLS`（既定60）/ `ACTIVE_MONTHLY_AI_CALLS`（既定1500） | 429 `user_quota_exhausted`（上限回数と戻る時刻つき） |
| L2 日次予算 | 見積り額を**呼ぶ前に**予約。試用と有料でプールを分ける | `LLM_DAILY_BUDGET_MILLI`（試用・既定1500＝$1.5）/ `LLM_PAID_DAILY_BUDGET_MILLI`（有料・既定3000＝$3） | 429 `daily_budget_exhausted`「本日のAI処理の上限に達しました」 |
| fail-closed | カウンタ（D1 `cost_counters`）に繋がらない・env が数値として読めない → 呼ばない | — | 503 `cost_guard_unavailable` |
| タイムアウト | fetch を時間で打ち切る | `LLM_TIMEOUT_MS`（既定25000） | 502（各入口の既存の失敗応答） |

- カウンタは D1 の1文 `INSERT … ON CONFLICT DO UPDATE … RETURNING`（原子的）。KV は読んでから書くので同時の2件が両方通るため使わない。
- 見積り（`estimateCallMilli`）は**文字数をそのままトークン数**として、モデルの単価表で計算する（日本語は多めに出る側）。
  **単価表に無いモデル**（`APP_MODEL` を高いモデルに変えた等）は最上位クラスの単価（入力$15/出力$75 per 100万）で見積もるので、日次予算がすぐ尽きて止まる。
- 呼んだ後に失敗しても予約は戻さない（課金済みかもしれないので、多く数える側に倒す）。
- `callOpenRouter`（llm.js）は予約（`reservation`）を渡されないと fetch せずに断る。新しい入口を足すときに予約を忘れると、その場で動かない。

## 3. 黒字の式（§A-4 の表。★数字は提案）

為替は 1ドル=150円で計算。単価は OpenRouter の目安を安全側に丸めた値（`src/cost-guard.js` の `MODEL_PRICES`）。

| 項目 | 値 | 根拠 |
|---|---|---|
| 原価 c（1操作） | 判定 ≈0.09円（救済込みで最大 ≈0.28円）／下書き ≈0.07円／案件照合 **最大 ≈0.5円** | gemma-3-12b: 入力$0.1・出力$0.2 per 100万。案件照合 = 30,000字 + 1,500トークン ≈ 3.3ミリドル |
| 無料枠 F | ログイン利用者1人あたり **試用14日間で60回**（全部を最大原価で使っても 60 × 0.5 = **30円**） | `TRIAL_AI_CALLS` |
| 有料 P / N | **月額2,980円 / 月1,500回まで**（`knowledge-pack/docs/pricing-trial.md` の価格） | `ACTIVE_MONTHLY_AI_CALLS` |
| 有料の粗利（1人・月） | 最悪 2,980 − 1,500 × 0.5 − 決済手数料(約3.6%≒107) ≈ **2,120円**。普段使い（月300回・平均0.1円）なら ≈ 2,840円 | 決済手数料の率は未確認（Stripe 想定） |
| 損益分岐の課金率 r* | 最悪 30 ÷ 2,120 ≈ **1.4%**（試用した人の70人に1人が有料にすれば黒字）。普段使いなら ≈ 0.1% | 正本の目安 2% 以下を満たす |
| 匿名の全体予算 | **0円**（匿名の入口から LLM を呼ばない） | すべて `requireAuth` の後 |
| 最悪の日の損 | 試用プール $1.5 + 有料プール $3 = **$4.5/日（約675円）**、月 約2万円 | 有料プールは売上と相殺されるので、実際の持ち出しは試用プールの約225円/日まで |

★試用を100回にすると最悪の r* は 50 ÷ 2,120 ≈ 2.4% で目安を超えるので、既定値は60回にした。
